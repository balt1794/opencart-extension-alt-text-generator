**Description** (paste, then format the bullets with the list buttons)

```
Write SEO-friendly alt text for every image in your OpenCart shop, in one click.

Alt Text Generator AI finds the images used by your products, categories, brands and banners, writes a description for each one with AI, lets you review and edit it, and puts it into your storefront as the image's alt text. OpenCart has no alt field for images and uses the product name, so most shops end up with images that say nothing about what they show. This fixes that in minutes.

What you get
- Bulk page under Catalog: see every image that has no alt text, generate for all of them or only the ones you tick
- Review before saving: edit any text, then save everything at once
- Works with your theme: no theme files or template edits, no OCMOD or vQmod. It adds the text to the finished page, including resized images and lazy-loaded images
- 131 languages: choose the language of the alt text and the store language it is saved for
- Safe: images that have no alt text keep OpenCart's default, and removing the extension brings your shop back to the default
- Your API key stays on your server and is never sent to the browser

Works with OpenCart 3 (3.0.2 and newer) and OpenCart 4 (4.1). Download the file that matches your version.

How it is priced
The extension is free. Writing alt text uses credits from your Alt Text Generator AI account: one credit per image. New accounts get free credits to try it, and you can add more at alttextgeneratorai.com. A resized copy of the image is sent to alttextgeneratorai.com when you generate. Images are not stored.

Support: support@alttextgeneratorai.com
```

## Documentation

```
Install
1. Download the file for your version: altai.ocmod.zip for OpenCart 4, altai_oc3.ocmod.zip for OpenCart 3.
2. Open Extensions > Installer, upload the file and click the green Install button.
3. Open Extensions > Extensions, choose Modules in the list, find Alt Text Generator AI, click the green + to install it, then the blue pencil to open it.
4. Paste your API key (free at https://alttextgeneratorai.com/dashboard), make sure Status is on and save.

Use it
1. Open Catalog > Alt Text Generator AI. It lists the images used by your products, categories, brands and banners, and shows your credits.
2. Missing shows images with no alt text. All shows everything.
3. Tick the images you want, or leave them all unticked, then click Generate selected or Generate all missing. Each image uses 1 credit.
4. Read the results, edit anything you like and click Save changes.
5. Open a product page and look at the image's alt attribute in your browser. It now holds the new text.

Languages
Language of the alt text is the language the text is written in. Save for store language is the shop language whose visitors see it. If your shop has several languages, generate and save once for each.

Uninstall
Extensions > Extensions > Modules > Alt Text Generator AI > red button. The alt texts you wrote are kept, so installing again brings them back. OpenCart removes the settings, including the API key, so paste the key again after installing.

Troubleshooting
- "Invalid API key": copy the key again from https://alttextgeneratorai.com/dashboard
- "No credits left on this API key": add credits at https://alttextgeneratorai.com
- Alt text does not show on the storefront: check Status is on and clear the theme cache.

Support: support@alttextgeneratorai.com
```
